# Blockchain Transaction Anomaly Detection using Graph Neural Networks

An end-to-end empirical study of Graph Neural Networks (GNNs) for detecting illicit Bitcoin transactions, including the **first rigorous cross-dataset transfer evaluation** of GNN-based AML models on public datasets.

**🚀 Live Demo:** [**Try it on HuggingFace Spaces →**](https://huggingface.co/spaces/rudranil7/blockchain-aml-demo)

**Key finding:** A GraphSAGE model trained on the Elliptic Bitcoin dataset suffers a **97% F1 drop** when evaluated on IBM AMLWorld, and its ROC-AUC falls to **0.305 — worse than random**. This suggests that single-dataset benchmarks substantially overstate the deployment readiness of current GNN-based AML systems.

---

## 📊 Results at a Glance

| Experiment                          | Dataset    | F1        | ROC-AUC   |
|-------------------------------------|------------|-----------|-----------|
| Random Forest (no graph)            | Elliptic   | 0.817     | —         |
| GraphSAGE                           | Elliptic   | 0.663     | —         |
| GAT                                 | Elliptic   | 0.590     | —         |
| GCN                                 | Elliptic   | 0.471     | —         |
| EvolveGCN-O (temporal)              | Elliptic   | 0.473     | —         |
| DOMINANT (unsupervised, no labels)  | Elliptic   | —         | 0.768     |
| **Elliptic → AMLWorld (cross)**     | both       | **0.012** | **0.305** |
| **AMLWorld → Elliptic (cross)**     | both       | **0.092** | **0.553** |

Three notable secondary findings:
- **Temporal-shift gap:** Random data splits inflate F1 by **0.212 points** on Elliptic compared to the realistic temporal split.
- **DOMINANT recovers 55% of supervised PR-AUC with zero labels**, demonstrating the value of unsupervised methods when labels are unavailable.
- **Random Forest beats every GNN** on the standard Elliptic benchmark, replicating the canonical Weber et al. (2019) result.

## 🚀 Quick Start

### Installation

```bash
git clone https://github.com/YOUR_USERNAME/blockchain-aml-gnn.git
cd blockchain-aml-gnn

# Create virtual environment
python -m venv venv

# Activate it
# Windows:
venv\Scripts\activate
# Mac/Linux:
source venv/bin/activate

# Install dependencies
python -m pip install -r requirements.txt
```

### Run the Demo Locally

```bash
python app.py
```

Open `http://localhost:7860` in your browser. The Elliptic dataset auto-downloads on first run (~15 MB).

The demo has two tabs:
- **Tab 1 — Transaction Lookup:** Paste a Bitcoin transaction ID; see the 2-hop neighborhood with illicit nodes in red and licit in green.
- **Tab 2 — Cross-Dataset Failure:** Visualizes the headline finding (97% F1 drop on transfer).

Or try the deployed version directly: [**huggingface.co/spaces/rudranil7/blockchain-aml-demo**](https://huggingface.co/spaces/rudranil7/blockchain-aml-demo)

**Example transaction IDs to try:**

| Type    | Transaction IDs                            |
|---------|--------------------------------------------|
| Illicit | `232629023`, `230389796`, `17387772`       |
| Licit   | `232438397`, `232029206`                   |

### Reproduce Stage 1 (static GNN baselines)

```bash
python train_all.py
```

Runtime: ~5 minutes on a 4 GB GPU. Trains all five baselines (LogReg, RF, GCN, GraphSAGE, GAT) on the temporal split.

### Reproduce Stage 2 (temporal + unsupervised + ablations)

```bash
python build_snapshots.py          # builds per-timestep snapshots
python train_evolvegcn.py          # 2.1 — EvolveGCN-O
python train_dominant.py           # 2.2 — DOMINANT autoencoder
python train_focal.py              # 2.3 — Focal vs Weighted CE
python train_shift.py              # 2.4 — Temporal vs Random split
```

### Reproduce Stage 3.1 (cross-dataset transfer)

This study was run on Kaggle T4 GPUs. The full notebook code is in `PROJECT_FULL_STATE.md`. The required dataset is the IBM AMLWorld HI-Small from Kaggle:
- [kaggle.com/datasets/ealtman2019/ibm-transactions-for-anti-money-laundering-aml](https://www.kaggle.com/datasets/ealtman2019/ibm-transactions-for-anti-money-laundering-aml)

## 🔬 Methodology Summary

We construct a five-stage end-to-end pipeline:

1. **Static GNN baselines** on Elliptic with the realistic temporal train-test split (timesteps 1–34 train, 35–49 test).
2. **Temporal modeling** with EvolveGCN-O (LSTM-evolved GCN weights) plus three ablations.
3. **Unsupervised detection** with the DOMINANT graph autoencoder.
4. **Scaling** to Elliptic2 (49M-node background graph) via SubgraphSAGE on Kaggle T4 GPUs.
5. **Cross-dataset transfer** via a shared 11-dimensional structural feature space.

The cross-dataset experiment is the central contribution. The 11-dimensional shared feature space uses only dataset-agnostic graph-structural quantities (log degrees, log PageRank, log 2-hop reach, in/out ratio, normalized degree) plus four standardized raw features, ensuring that observed transfer failure is not a feature-mismatch artifact.

For full details, see `PROJECT_FULL_STATE.md`.
